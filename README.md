# Nocturne — Ultra Luxury Cinematic Couple Website

## Stack
Next.js (App Router), TailwindCSS, Framer Motion, GSAP, Lenis, Supabase.

## Setup
1. `npm install`
2. Copy `.env.example` to `.env.local` and set keys.
3. Run SQL in `sql/schema.sql`.
4. Create Supabase storage bucket: `memories` (public).
5. `npm run dev`

## Features
- Cinematic preloader and immersive editorial homepage
- Timeline, masonry gallery, love letter section, luxury dark UI
- Supabase auth pages (login/register)
- Realtime notes in private dashboard
- Upload API for memory assets
- Vercel-ready Next.js app router project
